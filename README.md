# ⚡ Streamlit Pokémon Pokédex

A sleek, interactive Pokédex web application built with Python, Streamlit, and the PokéAPI. 

## ✨ Features
- **Search any Pokémon:** Look up stats, height, weight, types, and moves by name.
- **Customizable Info View:** Use multiselect options to choose exactly what details you want to display.
- **Form Switcher:** Toggle between Base Forms, Mega Evolutions (X/Y), and Primal Forms using a sidebar layout.
- **Authentic Type Badges:** Color-coded visual badges matching official Pokémon type aesthetics.

## 🛠️ Tech Stack
- **Python**
- **Streamlit** (for the interactive frontend UI)
- **Requests** (for fetching data from the API)
- **PokéAPI** (as the backend data source)
